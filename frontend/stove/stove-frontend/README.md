# Как запустить проект
* как обычно -- выполнить клонирование репозитория
```git 
  git clone <...>
```
* перейти в папку `frontend/stove/stove-frontend`
```
    cd frontend/stove/stove-frontend/
```
* убедиться, что у вас установленны `Node.js` и `npm`
* запустить проект командой
```
    npm start
```
